# Smart_WASTE_APP


Overview

The Waste Management App is a mobile application designed to encourage sustainable waste disposal practices by helping users manage and recycle their waste effectively. The app provides eco-friendly tips based on the user's location and allows them to sell plastic waste in exchange for virtual coins, which can be used to purchase recycled products.

Features

User Authentication: Secure login and authentication using Firebase.

Flutter UI: A clean and responsive user interface built using Flutter.

State Management: Efficient app state handling using Flutter BLoC.

Eco-Friendly Tips: Users receive location-based sustainability tips to promote better waste disposal.

Plastic Selling & Reward System: Users can sell plastic waste and earn virtual coins.

Marketplace: Users can redeem their earned coins to purchase recycled products.

Tech Stack

Framework: Flutter

State Management: Flutter BLoC

Authentication: Firebase Authentication

Installation & Setup

Clone the Repository

git clone https://github.com/your-username/waste-management-app.git
cd waste-management-app

Install Dependencies

flutter pub get

Configure Firebase

Set up a Firebase project and enable Authentication.

Download and place the google-services.json file (for Android) in android/app/.

For iOS, configure Firebase accordingly.

Run the App

flutter run

Usage

Login/Register securely using Firebase Authentication.

Access Eco-Friendly Tips based on location.

Sell Plastic Waste to earn virtual coins.

Use Earned Coins to purchase products from the marketplace.
